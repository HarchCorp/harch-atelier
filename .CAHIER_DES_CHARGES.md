## MÉCANISME DE FIN DE SESSION

### Règle absolue
Une session ne peut être terminée QUE si:
1. Toutes les clauses BLOCKING sont en statut PASS
2. Le rapport de conformité est écrit dans `.session-lock.json`
3. Le champ `sessionCanEnd` est `true`

### Procédure de fin de session
1. L'exécuteur appelle `bun --ts scripts/enforce-cahier.ts`
2. L'enforceur exécute toutes les vérifications
3. Si toutes les BLOCKING passent → `sessionCanEnd: true` écrit dans `.session-lock.json`
4. Si une BLOCKING échoue → `sessionCanEnd: false` + liste des clauses restantes
5. L'exécuteur doit corriger les clauses échouées avant de retenter

### Anti-triche
L'enforceur est un script TypeScript indépendant qui:
- Ne peut pas être modifié par l'exécuteur (droit limité)
- Lit le .CAHIER_DES_CHARGES.md directement du système de fichiers
- Exécute les vérifications en temps réel
- Écrit le résultat dans .session-lock.json (contrôlé par l'enforceur)
- L'exécuteur ne peut pas écrire manuellement `sessionCanEnd: true`
