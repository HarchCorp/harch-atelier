# HARCHIQ SKILLS — Brainstorming Massif de A à Z

> Méthode : 1 skill = 1 livrable (pas du chat). Chaque skill ouvre une popup avec un document qui se génère en direct. Même design system, mêmes couleurs, mêmes icônes, même bibliothèque.
>
> Priorité : construire un par un. Tester. Si 2/10 → changer le prompt. Si 8/10 → garder et passer au suivant.

## TEMPLATE DE BASE (pour tous les skills)

Chaque skill partage :
- **Design** : White bg, sage #4A7B5F, charcoal #0A0A0A, Space Mono headers, Inter body
- **Bibliothèque** : recharts (charts), framer-motion (animations), shadcn/ui (Card, Button, Dialog)
- **Structure** : Bouton → Popup → Document qui se génère en direct → Export PDF/PPT
- **Données** : API existantes (/api/console/*) + Hespress scraper + company matching
- **Langue** : Français, NO emojis, Lucide icons
- **Persistance** : localStorage pour config, API pour données
