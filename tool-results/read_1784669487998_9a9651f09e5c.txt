  1112→- **Architectural decisions**: (1) All legal sections follow the trader + admin pattern exactly: `SectionHeader` (with `accent="violet"` for the legal role tint, `statusChips`, `kpis`) + `ChartCard` body + reusable `DeferredChart` for chart mounts. (2) Legal accent is violet-700 across all 8 sections for role identity (vs admin which rotated accents). (3) All tables use shadcn `<Table>` primitives with `max-h-[N] overflow-y-auto harch-scroll` for long lists. (4) All charts use recharts via `DeferredChart` to avoid ResponsiveContainer flash. (5) The legal dataset is fully self-contained — no `any`, deterministic, mulberry32 seeded so first paint is stable. (6) Sanctions heatmap uses a 0/1/2 exposure scale (None/Direct/Indirect) with cell intensity + a legend — denser than a boolean hit/no-hit. (7) Matters docket color-codes the 8 matter types with a distinct hue per type (Litigation=rose, Arbitration=violet, Regulatory=deep-violet, IP=sky, Contract=emerald, Compliance=amber, Employment=teal, Real Estate=slate). (8) Hold register uses data-source chips with Database icon — visually distinct from the typical pill pattern.
  1113→- **Issues/risks**: (1) The `pillarColor` export in `legal-data.ts` duplicates the one in `admin-data.ts` with the Regulatory pillar re-tinted to violet-700 (matching the legal role tint). This is intentional — each role owns its pillar color identity — but downstream agents should import from `legal-data` for legal sections and `admin-data` for admin sections to avoid tint conflicts. (2) The Counterparty table has 8 columns which gets tight on mobile; the search input truncates gracefully but a horizontal scroll would be a future enhancement. (3) The Sanctions Heatmap is a sticky-header HTML table with `min-w-[760px]` and `overflow-x-auto` — works on desktop, mobile users will need to scroll horizontally (acceptable for a dense compliance matrix). (4) The trade-policy timeline shows future events with violet-700 date tiles and past events with slate-800 tiles — the 14-day "in Xd" / "Xd ago" relative labels are anchored to the 2025-11-15 timestamp (consistent with the rest of the app). (5) The matters donut has a single rendered legend; in production a click-to-filter would be a nice addition. (6) The Reputational section's stakeholder sentiment uses manual divs rather than recharts because recharts stacked bars don't render inline labels cleanly at narrow widths — the manual approach gives precise control over the inline % labels.
